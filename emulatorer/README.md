# Emulatorer / Emulators

- [`enkel/`](enkel/): en mycket enkel emulator i C, byggd på tinyz80:
  skärmminnet och några tangenter, utan grafik och ljud. *A barely
  functional emulator in C, built on tinyz80.*
- [`pico/`](pico/): *ABC80 for Ants*, emulatorn för Raspberry Pi Pico 2
  i fyra steg, från skärm och tangentbord (01) till filer (02), ljud
  och VGA (03) och AIR-FIGHT (04). *The emulator for Raspberry Pi Pico 2
  in four steps.*

Den fullständiga emulatorn till boken, med kassett, diskett och ljud,
i terminalen och i webbläsaren, finns i
[`../inifran/emulator/`](../inifran/emulator/).

*The full emulator for the book, with tape, disk and sound, in the
terminal and in the browser, is in
[`../inifran/emulator/`](../inifran/emulator/).*
