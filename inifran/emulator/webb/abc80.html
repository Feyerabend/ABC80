    Hur den används
    
Klicka på skärmen och skriv. Enter är RETURN, ← och
    Backsteg backar, → går framåt, Ctrl+C
    är BREAK. Å, Ä, Ö, É och Ü skrivs som vanligt. Text som klistras in
    skrivs som tangenter, en rad i taget.

    
Filer går också att dra till sidan: en .wav blir ett band i
    kassetten, en .dsk en diskett och annat ett program som skrivs in.
    Disketten sitter i FD2 (kort 45) med ABC-DOS. Man stannar i BASIC:
    DOS:en lägger bara till enheterna DR0:–DR6:,
    så det är LOAD DR0:A.B eller RUN DR0:A.B.
    BYE kör CMDINT.SYS från disketten, om den finns där.
    BASIC:en kan inte lista katalogen (det gjorde programmet LIB på
    systemskivan), så Katalogen visar filerna och hur många sektorer
    de tar. Det som sparas med SAVE DR0:NAMN hamnar bara i
    sidans minne; Spara disketten laddar ner den som en
    .dsk, som går att lägga i igen.

    
Kassetten: lägg i ett band och skriv LOAD CAS: eller
    RUN CAS:. Skriv inget medan blocken läses, det ger ERR 35. För
    att spela in: tryck Spela in, skriv SAVE CAS:NAMN och
    tryck sedan Spara inspelning.

    
Bandets eget ljud hörs med ljudet på, medan bandet går i vanlig fart.
    Med PLAY nere (ikryssad från början) stannar bandet inte när
    ROM:en slår av motorn, som på en bandspelare utan fjärrstyrning, och
    att kryssa i den startar bandet.

    
Exempeldisketten lägger i en diskett med fyra program: skriv
    RUN DR0:GISSA (gissa talet), RUN DR0:KURVA
    (kurvor med SETDOT), RUN DR0:MUSIK (en orgel
    från 1981 på tangenterna Z, X, C … med S, D, G … som de svarta, med
    Caps Lock eftersom programmet väntar sig versaler) eller RUN DR0:AIRFIGHT
    (spelet från 1981 i Z80-kod, för två: A, D och X mot J, L och M;
    laddaren tar en halv minut). Samma fyra program finns också som band,
    ett per program, i exempel/program/kassett/ (Lägg i
    band… och RUN CAS:), och som text i
    exempel/program/text/ (Skriv in… och
    RUN).

    
CMOS-minnet är 2 KB RAM på $5000–$57FF
    (20480–22527), som det batteriförsedda minnet på Super Smartaid. Det
    som står där sparas i webbläsaren och finns kvar när sidan laddas om
    eller maskinen startas om: POKE 20480,42, ladda om, och
    PRINT PEEK(20480) ger 42. Spara och Ladda…
    flyttar det som en fil (i terminalen: -M cmos.bin).

    
Forth-kretsen sätter Forth-tolken från exempel 7 (band 2) i
    en krets på $4000, där Smartaid satt, och startar om
    maskinen. Kretsen kan inte skrivas i, så de egna orden läggs i RAM från
    $C000, och BOFA flyttas upp först:
    POKE 65052,0,208 och NEW. Sedan startar
    Z=CALL(16384,3) tolken: : KV DUP + ; och
    7 KV . ger 14. WORDS listar orden, och
    @ skrivs É. BYE går tillbaka
    till BASIC och Z=CALL(16384,4) fortsätter med de egna
    orden kvar. Samma tolk finns som band i bokens kodförråd
    (inifran/forth/FORTH.wav), för RAM på $C000.

    
Forth med CMOS är samma tolk, men de egna orden läggs i
    CMOS-minnet, och radbufferten också, så ingen POKE behövs:
    Z=CALL(16384,3) direkt. Orden finns kvar när sidan laddas
    om. EMPTY tömmer ordlistan.

    
Länkar kan ge tangenter att skriva efter starten:
    abc80.html?k=10 PRINT "HEJ"\r20 GOTO 10\rRUN\r, med
    \r för RETURN och \w500 för en paus i ms.
    ?rom=gammal väljer den gamla ROM:en, ?ljud=av
    och ?cmos=pa slår på CMOS-minnet.

    
Ljudet är på, men webbläsaren släpper inte fram det förrän man har
    klickat på sidan eller skrivit något.
